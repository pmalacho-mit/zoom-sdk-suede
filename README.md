# Zoom-sdk-suede

This repo is a [suede dependency](https://github.com/pmalacho-mit/suede).

To see the installable source code, please checkout the [release branch](https://github.com/pmalacho-mit/zoom-sdk-suede/tree/release).

## Installation (SSH)

```bash
git subrepo clone --branch dist git@github.com:pmalacho-mit/zoom-sdk-suede.git ./zoom-sdk-suede
```

## Installation (HTTPS)

```bash
git subrepo clone --branch dist https://github.com/pmalacho-mit/zoom-sdk-suede.git ./zoom-sdk-suede
```
